Past Projects · Sleep & Memory

Targeted Memory Reactivation

Replaying a sound during sleep to strengthen one specific memory: an EEG-ready PsychoPy experiment in the style of Rudoy et al. (2009).

✦

What it does

Participants learn where each of a set of objects appears on screen, and each object is paired with a characteristic sound. Their spatial memory is tested before and after a nap. During slow-wave sleep, the sounds for half of the well-learned items are quietly replayed. If reactivation during sleep strengthens those memories, the cued items should be recalled more accurately afterward than the uncued ones.

The script runs the whole session phase by phase: study, a drag-to-location pre-test, a within-subject random cue assignment, operator-supervised cueing during sleep (with arousal flagging and settling intervals), and a matching post-test. Every phase writes its own CSV, so a crash mid-session never loses data.

Spatial memory measure

Recall is scored as the distance in pixels between where the participant places the marker and where the object really was. The measure is the drop in error from pre- to post-test.

error = ‖response − target‖

Cueing during sleep

Cued sounds play in interleaved rounds at a low volume, with jittered 4.5–5.5 s gaps. The operator can flag arousals, classify them, and let the participant settle before cues resume.

cued vs. uncued, within subject

EEG triggers

Events are time-stamped to EGI NetStation, with 4-character codes for study, test, cue, and arousal events. Visual onsets are locked to the screen refresh.

My adaptation

I built my version from a starter paradigm and adapted it for our lab's EEG setup:

  • Moved to the newer egi_pynetstation API, with the iohub keyboard backend so key handling doesn't interfere with the NetStation connection.
  • Resync the amplifier clock before every phase, trial, and cue, so triggers stay aligned and the connection never goes idle.
  • Made visual triggers screen-synced, firing on the exact frame the stimulus appears.
  • Automatically route audio to the lab computer's headphones, falling back to the default device on any other machine.
  • Switched to a new stimulus set with a wider reference grid.
